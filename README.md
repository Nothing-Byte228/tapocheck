# TapoCheck
Мой старый мессенджер, сделанный с помощью ИИ за 3 дня.

## На чём он сделан
Мессенджер сделан на Python используя фреймворк `Flask`.

## Как его использовать
Чтобы использовать мессенджер, вам необходимо следовать этим простым шагам:

1. Установить репозиторий себе на компьютер (также для этого понадобится Python)
2. Запустить файл `init_dbs.py` (это создаст все необходимые базы данных)
3. Запустить сам мессенджер (файл `app.py`)

## Будут ли обновления
Нет, этот проект больше не обновляется из-за массы уязвимостей, которые он содержит в себе. На момент создания этого описания действующая ссылка на мессенджер в вебе находится [здесь](https://tapocheck.pythonanywhere.com/) (она может перестать действовать).
